Project Mission & Architectural Thesis

This portfolio serves as both my personal digital identity and an active laboratory for Human-AI Symbiotic Software Engineering. Rather than using conventional boilerplate templates, this application was built through conversational context orchestration, architectural prompt engineering, and rigorous iterative code reviews with AI coding agents in Google AI Studio Build.

The objective was to test the practical boundary of natural-language driven development: creating a high-performance, accessible, and mathematically disciplined website spanning 3D vector graphics, real-time computer vision, empirical cognitive psychology testing, and custom Constructivist design systems without accumulating technical debt or relying on generic "AI slop" visual clichés.

Key Subsystems & Engineering Highlights

3D Interactive TopoJSON Orthographic Globe

Engineered a canvas-rendered 3D globe powered by D3.js v7 and TopoJSON vector geometries (110m resolution). Features:

  • Quaternionic rotation kinetics with smooth inertia dragging and momentum decay.
  • Geodetic distance calculation for back-face culling (only markers on the visible hemisphere render).
  • 15 pinned geographic coordinates spanning Australia, Japan, Europe, the Caribbean, and North America.
  • Interactive hover hit-testing displaying high-contrast tooltip callouts and animated radar pulses.

WebRTC Computer Vision Laboratory (Photo Booth)

An in-browser hardware-accelerated video processing pipeline built on HTML5 Canvas API and WebRTC media streams:

  • 10 real-time math filter shaders (Andy Warhol 4-quadrant RGB offset, infrared thermal heat mapping, non-linear fisheye coordinate deformation, and vintage CRT scanlines).
  • 3-second animated countdown sequencer with visual screen-flash snapshot shutter.
  • Client-side reel buffer enabling instantaneous high-resolution PNG export with zero server upload.

Empirical Cognitive Psychology Battery (The Stroop Effect)

A laboratory-grade neuropsychological assessment quantifying executive cognitive inhibition and attention conflict:

  • High-resolution millisecond latency timers measuring response reaction times on congruent vs. incongruent stimuli.
  • Automated calculation of individual Stroop interference penalties and error distributions.
  • Comparative analysis juxtaposing biological cognitive heuristics with adversarial vulnerabilities in artificial neural classifiers.

Constructivist Design System & Dual-Theme Architecture

Architectural design inspired by early 20th-century Constructivism, balancing visual order and functional hierarchy:

  • Dynamic CSS variable token architecture with instant toggle between high-contrast Dark and Light palettes.
  • Robust client storage fallbacks preventing state exceptions in sandboxed iframes.
  • Progressive enhancement scroll-reveal observers and interactive hero particle mesh visualizers.

Human-in-the-Loop Methodology

This project proves that the most effective AI-assisted engineering relies on strict architectural constraints. Every prompt was carefully scoped to define mathematical ratios, WCAG AA color contrasts, defensive programming patterns (such as iframe storage guards and WebRTC permission fallbacks), and modular separation of concerns.

The code is version-controlled via GitHub, bundled with Vite multi-page Rollup orchestration, and automatically deployed to GitHub Pages through GitHub Actions CI/CD workflows.
